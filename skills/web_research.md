# Skill: Web Research

When gathering information from the web:
- Search for multiple angles on the topic, not just the first result
- Prioritise recent sources — note publication dates where visible
- Record the source URL for every key finding
- Distinguish clearly between: confirmed facts, expert opinions, and speculation
- Acknowledge when sources conflict or information is incomplete
- Format findings in markdown: use **bold** for source names, bullet points for findings, and include the URL inline as a markdown link — e.g. `- **Finding** ([source](url))`
- Do not fabricate sources — only report what was returned by the search tool
